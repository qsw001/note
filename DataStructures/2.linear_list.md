# 线性表

线性表：线性表是具有相同数据类型的n个数据元素的有限序列，其元素之间是一对一的关系，即除第一个元素外，其他每个元素有且仅有一个直接前驱，除最后一个元素外，其他每个元素有且仅有一个直接后继。

线性表的特点：
- 同一性：同一个表中的所有元素的数据类型必须相同
- 有序性：线性表中的元素是有序的......
- 有限性：线性表是由有限个元素组成，线性表中的元素个数n称为线性表的长度，当n = 0时，线性表称为空表。

## 1. 顺序表

顺序表是一种线性表的顺序存储结构，其特点为：
- 数据元素在物理（内存）上连续存放
- 每个数据元素占用相同大小的存储单元
- 可通过下标访问任意元素（随机访问）

## 链式归并

链式归并的问题为将两个由小到大的链表合并为一个由小到大的大链表。

这里我们需要初始化三个指针，这里我分别称他为新链表指针p = head1，第一个链表指针p1 = head1->next,第二个链表指针p2 = head2->next

其操作过程为比较p1与p2的数据，如果p1比p2小，将p的next指向p1，p1指向他的next指针，如果p1比p2大，反之，最后p指向它的下一个指针。
