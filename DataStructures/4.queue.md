# 队列

## 1.1 队列的概念

队列：队列是一种先进先出(FIFO)的线性数据结构，其抽象定义为一个受限的线性表，其操作受限在两端进行。

## 1.2 循环队列

通过使用取模操作，模拟出队列循环的效果，防止溢出。

### 1.2.1 循环队列的基本结构

```
typedef struct queue {
	int data[MAX];
	int rear;
	int front;
}queue;
```

### 1.2.2 循环队列的基本操作

- 初始化队列(initQueue)
    ```
        void initQueue(queue* q) {
            q->front = q->rear = 0;
        }
    ```

- 出队(enqueue)
    ```
        int dequeue(queue* q) {
            if (isEmpty(q)) {
                printf("队列为空\n");
                return 0;
            }
            int x = q->data[q->front];
            q->front = (q->front + 1) % MAX;
            return x;
        }

    ```
- 入队(dequeue)
     ```
        void enqueue(queue* q,int x) {
            //队列满，报错误信息
            if ((q->rear + 1) % MAX == q->front) {
                printf("队列满\n");
                return;
            }
            q->data[q->rear] = x;
            q->rear = (q->rear + 1) % MAX;
        }
    ```
- 取对头元素(getFront)
    ```
        int getFront(queue* q) {
            if (isEmpty(q)) {
                printf("队列为空\n");
                return 0;
            }
            return q->data[q->front];
        }
    ```
  
- 判断队列是否为空(isEmpty)

    ```
        int isEmpty(queue* q) {
            return q->front == q->rear;
        }
    ```

## 1.4队列的易错点及补充

区分循环队列的空和满的方法有三种：
- 牺牲一个存储单元
- 增加size存储当前元素数量
- 增加tag标志上一次操作类型front==rear&&tag==0/1;

说说牺牲一个存储单元的形式，(rear+1)%maxSize==front，初始化时，front和rear的值均为0，所以front = a,rear = b时，中间一共有b-a个数，即front指向的数组中(没有值)。

链式队列：
- 头指针指向头节点，尾指针指向尾节点
- 判空：rear = front
- 入队：尾插法
- 出队：删除front->next
- 优点：不会队满
- 缺点：需要指针

队列的特点：
- 先进先出
- 两段操作，队首出队，队尾入队。

队列的假溢出现象：顺序队列的尾指针到达了队尾，但是前端还有位置，队列还不能如对的现象，我们称其为假溢出，解决方案是：改为循环队列。
